# SEO audit — ДаДом

Дата: 25 ноября 2026

## Что сделано

- Главная имеет единый H1 `Дома для жизни на Урале`, title и description из SEO Foundation.
- Для страниц используется canonical, а индексирование включается только при `NEXT_PUBLIC_SITE_URL` (HTTPS-домен) и `SITE_INDEXABLE=true`.
- `robots.txt` и `sitemap.xml` генерируются из одних данных; непубличные маршруты, черновики и визуальные превью не включаются.
- Страницы проектов, портфолио, технологий и статей строятся только из опубликованных записей. При отсутствии данных они не имитируют ассортимент и закрыты от индексации.
- Динамические неизвестные slugs возвращают 404 через `notFound()`.
- Добавлена безопасная заготовка событий аналитики без идентификаторов счётчиков и без передачи имени/телефона.

## Найденные риски и решения

| Риск | Статус | Решение |
| --- | --- | --- |
| Демонстрационные проекты и цены могли выглядеть как реальные предложения | устранён | Каталог использует только `published`-данные; на главной — честное состояние ожидания публикации. |
| Визуальное превью могло быть доступно в production | устранён | В indexable-сборке `/visual-preview` возвращает 404 и запрещён в robots. |
| Контакты, юридические реквизиты, реальные цены и сроки не подтверждены | открыт | Поля в `src/data/company.ts` оставлены пустыми; не добавлять их без источника. |
| Обработчик заявок не настроен | открыт | Модальное окно не показывает ложный успех: нужен `NEXT_PUBLIC_LEAD_ENDPOINT` с реальным серверным подтверждением. |
| Публикация материалов без технической проверки | предотвращён | У контента есть статусы `draft` / `published`; в sitemap идут только published. |

## До запуска индексации

1. Указать `NEXT_PUBLIC_SITE_URL=https://dadom.pro` и `SITE_INDEXABLE=true` только в production.
2. Добавить подтверждённые юридические, контактные и сервисные данные.
3. Загрузить реальные проекты, фотографии с правами использования и даты публикации.
4. Проверить HTML на production: `https://dadom.pro/`, `/robots.txt`, `/sitemap.xml`.

## Что не делать

- Не публиковать вымышленные отзывы, цены, сроки, характеристики или фотографии.
- Не добавлять массово пустые города, районы и страницы фильтров.
- Не указывать `noindex` как защиту доступа: закрытые данные должны быть недоступны на уровне маршрута или сервера.
