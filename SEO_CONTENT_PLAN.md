# SEO content plan — ДаДом

## Принципы подготовки

План основан на Wordstat по Свердловской области за 24.10.2026–24.11.2026. Частотности используются для приоритизации тем, но не суммируются между вложенными запросами и не трактуются как уникальные пользователи.

На этом этапе не писать и не публиковать статьи автоматически. Для публикации каждого материала нужны автор, технический проверяющий, дата и дата обновления, подтверждённые источники, изображения с правами и привязка к реальным решениям компании.

## Архитектура каталога

Подготовлены вычисляемые категории, которые включаются только после появления подходящих опубликованных проектов:

- `/projects/category/barnhauzy` — барнхаусы;
- `/projects/category/odnoetazhnye` — одноэтажные дома;
- `/projects/category/dvukhetazhnye` — двухэтажные дома;
- `/projects/category/s-terrasoy` — дома с террасой;
- `/projects/category/dlya-postoyannogo-prozhivaniya` — дома для постоянного проживания.

Пока проектов нет, эти URL не генерируются, не индексируются и не попадают в sitemap. После наполнения у каждой категории должен быть самостоятельный список релевантных проектов — без автогенерированного SEO-текста.

## Следующий редакционный цикл

Перед публикацией каждой темы:

1. подтвердить решение у технического специалиста;
2. собрать собственные схемы, фото или иллюстрации с правами использования;
3. зафиксировать автора, проверяющего, источники и дату актуализации;
4. определить единственную целевую страницу темы после проверки поисковой выдачи;
5. добавить ссылки только на реально опубликованные проекты, комплектации и связанные материалы.
